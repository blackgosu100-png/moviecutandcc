# 🎬 쿠팡 영상 간편 편집기

타오바오 등 중국 사이트에서 받은 상품 영상을 **설치 없이** 간단하게 편집하는 도구입니다.

## 누구를 위한 도구인가요?

쿠팡 셀러 수강생용입니다. 복잡한 편집 프로그램(프리미어 등) 없이 아래 작업만 빠르게 할 수 있습니다.

- 🤖 **AI 자동 번역** — 영상 하단의 중국어 자막을 자동으로 찾아 한글 광고 카피로 번역하고, 가리개+한글 텍스트를 구간까지 맞춰 자동 추가 (무료 Gemini API 키 필요)
- 🎬 **타임라인 컷편집** — 캡컷처럼 화면 아래 영상/음성/자막/모양 4트랙 표시
  - ✂ 버튼으로 영상을 자르고, 조각을 클릭해 삭제/복원 (중간 부분도 잘라낼 수 있음)
  - 자막·모양 막대를 끌어서 시간 이동, 양끝을 끌어 길이 조절
- ⬛ **가리개 도형** — 중국어 자막/로고를 네모·둥근네모·원형·**모자이크**로 가리기 (배경색 추출 기능으로 자연스럽게)
- 가 **한글 텍스트** — 가린 자리 위에 한글 문구 넣기 (글씨체·크기·색·굵기·배경상자 조절)
- 😍 **이모티콘** — 🔥💯✨⭐ 등 자주 쓰는 이모티콘을 클릭 한 번으로 추가
- ⏱ **구간별 표시** — 가리개/텍스트를 중국어 자막이 나오는 구간에만 표시되게 설정
- 🎵 **배경음악 보관함** — mp3를 한 번 넣어두면 계속 재사용 (음량 조절, 자동 반복)
- ⏩ **배속** — 1.25배 ~ 4배까지 빠르게 (미리보기에도 그대로 적용)
- 💾 **임시저장** — 편집하던 영상과 상태를 브라우저에 보관했다가 이어서 작업
- 🔇 **소리 제거** — 중국어 음성 제거 (기본값)

## 사용 방법 (수강생 안내용)

1. **`index.html` 파일을 더블클릭**합니다. → 크롬(Chrome) 브라우저가 열립니다.
   - 설치할 프로그램이 없습니다. 인터넷이 끊겨 있어도 작동합니다.
   - 영상이 컴퓨터 밖으로 전송되지 않습니다. (전부 내 컴퓨터 안에서만 처리)
2. **영상 파일 열기** 버튼을 누르거나, 영상을 화면에 끌어다 놓습니다.
3. **⬛ 네모 가리개** 버튼을 누르고, 중국어가 있는 부분을 마우스로 드래그해서 덮습니다.
   - 네모를 클릭한 뒤 **💧 배경색 추출**을 누르고 영상의 배경 부분을 클릭하면, 배경과 똑같은 색이 되어 티가 안 납니다.
4. **가 텍스트** 버튼을 누르고 원하는 위치를 클릭 → 오른쪽 패널에서 한글 문구를 입력합니다.
5. **배속**을 고르고, 필요하면 **시작/끝 시간**으로 앞뒤를 잘라냅니다.
6. 중간 부분을 잘라내고 싶으면 화면 아래 **타임라인**에서:
   - 자르고 싶은 위치에서 영상을 멈추고 **✂ 현재 위치에서 자르기**를 누릅니다.
   - 빼고 싶은 조각을 **클릭**하면 어두워지며 완성 영상에서 빠집니다. (다시 클릭하면 복원)
   - 미리보기 재생도 잘라낸 부분을 자동으로 건너뜁니다.
7. **⬇ 영상 저장하기**를 누르면 완성된 mp4 파일이 다운로드됩니다.

## 주의사항

- **크롬(Chrome) 또는 엣지(Edge) 최신 버전**을 사용하세요. (최신 크롬에서는 mp4로 저장되고, 구버전에서는 webm으로 저장될 수 있습니다)
- 저장하는 동안 **탭을 닫거나 다른 창으로 가리지 마세요.** 저장은 실제 재생 방식이라 (영상 길이 ÷ 배속)만큼 시간이 걸립니다. 예: 30초 영상을 2배속 → 약 15초 소요.
- 키보드 `Delete` 키로 선택한 네모/텍스트를 삭제할 수 있습니다.

## 강사 전용: Codex CLI로 무제한 번역 (수강생 배포 시 자동 숨김)

API 키 비용 없이 ChatGPT 구독에 포함된 **Codex CLI**로 자동 번역을 돌리는 기능입니다.

1. Codex CLI 설치/로그인 확인: 터미널에서 `codex` 실행이 되어야 합니다.
2. `codex-bridge.bat` 더블클릭 (또는 `node codex-bridge.js`) → 연결 프로그램이 켜집니다.
3. 편집기(html)를 열면 AI 선택에 **"Codex CLI (내 컴퓨터) — 강사 전용"** 옵션이 자동으로 나타납니다.

연결 프로그램이 꺼져 있으면 이 옵션은 **아예 보이지 않습니다.**
따라서 수강생에게는 `index.html`(또는 `video_editor.html`) 파일만 전달하면
자동으로 Gemini/ChatGPT/Claude 3가지만 보입니다. `codex-bridge.js`/`codex-bridge.bat`는 전달하지 마세요.

## 강사용 배포 방법

- `index.html` 파일 하나만 수강생에게 전달하면 됩니다. (카톡, 메일, 강의자료 첨부 모두 가능)
- 또는 GitHub Pages 등에 올려서 링크 하나로 공유할 수도 있습니다.
